# TaskFlow — مدیریت کارها

یک برنامهٔ مدیریت کارهای هفتگی فارسی و راست‌چین با PHP، HTML، CSS و JavaScript. اطلاعات در فایل JSON ذخیره می‌شوند و به MySQL نیاز ندارد.

## امکانات
- داشبورد آماری برای هفته
- نمایش کارها از شنبه تا جمعه
- رفتن به هفتهٔ قبل و بعد
- افزودن، ویرایش، تکمیل و حذف کارها
- دسته‌بندی، اولویت و هدف هر کار
- طراحی واکنش‌گرا با فونت Vazirmatn

## اجرا در WampServer
1. پوشهٔ `taskflow` را در `C:\\wamp64\\www\\` قرار بده.
2. مطمئن شو Apache در حال اجراست.
3. این آدرس را باز کن: `http://localhost/taskflow/`
4. برای ذخیرهٔ کارها، PHP باید اجازهٔ نوشتن در پوشهٔ `data` را داشته باشد.

## اجرا در XAMPP
پوشه را داخل `C:\\xampp\\htdocs\\taskflow\\` قرار بده و به `http://localhost/taskflow/` برو.

## نکته
این نسخه برای استفادهٔ محلی و تک‌کاربره طراحی شده و ورود کاربران یا همگام‌سازی ابری ندارد.
